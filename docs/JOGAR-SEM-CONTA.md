# Jogar sem conta paga (conta offline)

O servidor aceita contas offline com senha. Passo a passo:

1. **Launcher:** o Prism oficial so deixa criar conta offline se o PC tiver uma conta Microsoft que comprou o
   Minecraft. Sem isso, use um launcher que aceite contas offline e importe arquivos `.mrpack` (por exemplo o
   Freesm Launcher, que e uma copia do Prism). Baixe so do site oficial do launcher.
2. **Conta offline:** crie uma conta offline com um **nome unico** (por exemplo `Pedro_CCC`). Nomes que ja
   pertencem a uma conta paga sao bloqueados.
3. **Modpack:** Adicionar instancia -> Importar -> cole o link do `.mrpack` da ultima versao:
   https://github.com/LuizMoratelli/cogs-claws-capes/releases/latest
4. **Memoria:** botao direito na instancia -> Editar -> Configuracoes -> Java -> memoria maxima **8192 MiB**.
5. **Mande seu nome exato** para quem cuida do servidor, para ele te liberar.
6. **Entrar:** Multiplayer -> Adicionar servidor -> `cairo-railroad.tun.ply.gg`
7. **Primeira vez no servidor:** digite no chat `/register suasenha suasenha`
8. **Nas proximas vezes:** `/login suasenha` (do mesmo IP, em ate 10 minutos, o login e automatico).

Esqueceu a senha? Peca para o dono do servidor resetar.
