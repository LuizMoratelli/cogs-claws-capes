# Playing Cogs, Claws & Capes

## Install (each player, once)

You need a paid Minecraft Java account and the pack file `cogs-claws-capes-<version>.mrpack` from the host.

1. Install **Prism Launcher**: https://prismlauncher.org (free, open source). It downloads the right Java by itself.
2. Log in: **Accounts -> Manage Accounts -> Add Microsoft**.
3. **Add Instance -> Import** -> pick the `.mrpack` file -> OK. Prism downloads Forge and all 79 mods.
4. Right-click the instance -> **Edit -> Settings -> Memory**: set **Maximum memory allocation to 6144-8192 MiB**
   (6-8 GB). Less than 6 GB will stutter.
5. **Launch.** The first start takes a few minutes.
6. **Multiplayer -> Add Server** -> paste the address the host gave you.

The Modrinth App and ATLauncher can import the same `.mrpack` file if you prefer them.

The host must have added your exact Minecraft name to the whitelist, or you will see "You are not white-listed".

## Progression

Press **R** on any item to see how it is made and **U** to see what uses it (JEI). Hover blocks to read them (Jade).

1. **Create basics:** andesite alloy, water wheel or windmill, then mechanical press, mixer and deployer.
2. **Fossils:** mine **fossil** blocks underground (Fossils & Archeology). Breaking them drops **Bio Fossils**,
   bones and relics. Bio Fossils go into the Analyzer to get **DNA**. Then: Culture Vat -> eggs -> your own dinosaurs.
3. **Brass:** brass ingots (mixer + blaze burner) -> **Precision Mechanisms** (sequenced assembly).
4. **Nether:** diamonds and **blaze rods**.
5. **Hero Core:** a sequenced-assembly line that takes a Precision Mechanism through 3 loops of
   *deploy Bio Fossil -> deploy Diamond -> deploy Blaze Rod -> press*.
6. **Tailoring Bench:** built in Mechanical Crafters, it needs a Hero Core. Every hero suit is made here, and **each
   suit costs another Hero Core**.
7. **Ben 10:** brush suspicious sand and gravel (archaeology) for alien **DNA codes**. The **Prototype Omnitrix** and
   its workbench are Mechanical Crafter recipes that need a Hero Core.
8. **Powers and gadgets** (serums, DNA, Iron Man add-ons, hero workstations) are made in **Mechanical Crafters** or a
   **heated Mixer**, and each needs a Hero Core.

9. **Magic (Iron's Spells):** spell books and scrolls drop from loot; the Inscription Table, Scroll Forge and Arcane
   Anvil are Mechanical Crafter recipes with a Hero Core.
10. **Bosses:** Cataclysm, Mowzie's Mobs and Ice and Fire dragons are tuned for strong players. Go in suited up.

Plan for a factory that makes Hero Cores automatically. That is where the whole group's Create, dinosaur and Nether
work comes together.

## Good to know

- Dying leaves a **corpse** with your items. Open it to get them back.
- **Waystones** are fast travel. **Open Parties and Claims** lets you protect your base: open Xaero's world map
  (`M` by default), right-click a chunk and claim it. Its own menu key is listed under Options -> Controls.
- Flying heroes and jetpacks are allowed on this server (`allow-flight=true`).
- Shaders: none are bundled. Embeddium is included for performance.
